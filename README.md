# Build Sheet 改裝帳本

給機車改裝玩家的記帳與展示工具。單一 HTML 檔，開啟即用，不需註冊。

## 兩種模式，一份資料

- **紀錄模式** — 統計卡（歷史總投入 / 現役價值 / 退役沉沒 / 待購）、各系統投入圖、零件增修刪、篩選搜尋
- **展示模式** — Build Sheet 版面，不顯示金額、依前後段分節、可掛照片與調校備忘，適合分享給車友

任一邊的修改即時反映到另一邊，永遠不需要維護第二份清單。

## 功能

- 五大分類（制動 / 懸吊 / 動力 / 外觀 / 其他）＋ 選填位置標籤（前段 / 後段）
- 完工價計價，符合車行連工帶料的報價習慣
- **附加費用** — 客製加工、調校工資掛在零件底下，自動併入該零件總花費
- **一鍵汰換** — 選定舊零件、填入新零件、記下回收金額，一次完成入帳與退役
- 願望清單 / 現役 / 已退役三種狀態
- 零件照片與封面照（上傳時自動壓縮）
- 可自訂的避震設定備忘卡

## 資料存在哪裡

資料只存在**你自己瀏覽器的 localStorage**，不會上傳到任何地方，開發者也看不到。

因此請注意：

- 換手機、換瀏覽器或清除瀏覽資料，資料就會消失
- 照片佔空間較大，存太多可能超過瀏覽器容量上限（頁面會提示）

**重要的資料請定期用「⬇ 匯出備份」存成 JSON 檔**，換裝置時再用「⬆ 匯入備份」還原。

## 使用方式

直接開啟網頁即可，或下載 `index.html` 到本機以離線方式使用。
